# DnD Hub

A full-stack toolkit for playing Dungeons & Dragons, featuring AI-powered
assistants for character creation, encounter building, dungeon mastering,
and collaborative session management.

## Tech stacks

| Layer | Technology | Hosting |
|---|---|---|
| Frontend | React + Vite | Vercel |
| Backend | Flask (Python) | Render |
| Database | Supabase (PostgreSQL) | Supabase cloud |

## Repository structure

- `backend/` — REST API built with Flask
- `frontend/` — Single-page app built with React
- `database/` — SQL migrations for Supabase
